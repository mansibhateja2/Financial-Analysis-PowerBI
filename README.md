# Financial Analysis Dashboard | Power BI

## Project Overview
This project focuses on analyzing financial data and developing an interactive dashboard using Microsoft Power BI.

The dashboard helps understand financial performance, identify trends, and generate meaningful business insights.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objectives
- Analyze financial performance.
- Track revenue and expenses.
- Identify financial trends.
- Compare financial metrics.
- Present insights through interactive visualizations.

## Dashboard Features
- Financial KPI Cards
- Revenue Analysis
- Expense Analysis
- Profit Analysis
- Trend Analysis
- Interactive Slicers and Filters

## Skills Demonstrated
- Data Cleaning
- Data Transformation
- Data Modeling
- DAX Measures
- Dashboard Development
- Business Intelligence
